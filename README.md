# Лабораторная работа №7 — Основы HTTP и PHP

**Дисциплина:** WEB-программирование

**Тема:** «Основы протокола HTTP. Базовые принципы написания серверных скриптов на языке PHP»

## Цель работы

Ознакомление с языком программирования PHP, его основными конструкциями и принципами серверной обработки данных. Закрепление навыков вёрстки и создания веб-страниц.

## Выполненные задания

1. **Рекурсия** (`task1.php`) — возведение числа в степень с помощью рекурсивной функции.
2. **Текущее время** (`task2.php`) — вывод времени с правильными склонениями часов и минут.
3. **Цикл while** (`task3.php`) — вывод чисел от 0 до 100, кратных трём.
4. **Цикл do...while** (`task4.php`) — определение чётных и нечётных чисел от 0 до 10.
5. **Цикл for** (`task5.php`) — вывод чисел от 0 до 9 без использования тела цикла.
6. **Массивы** (`task6.php`) — вывод областей и соответствующих им городов.
7. **Фильтрация массивов** (`task7.php`) — поиск городов, начинающихся с буквы «К».
8. **Транслитерация** (`task8.php`) — преобразование русского текста в латиницу.
9. **Обработка строк** (`task9.php`) — транслитерация с заменой пробелов на подчёркивания.
10. **PHP-калькулятор** (`task10.php`) — выполнение арифметических операций с использованием POST-запросов.
11. **Загрузка файлов** (`task11.php`) — загрузка файлов на сервер с проверкой типа и размера.

## Использованные технологии

## Запуск проекта

1. Установить XAMPP с поддержкой PHP.
2. Скопировать папку проекта `Lab7` в каталог `C:\xampp\htdocs`.
3. Запустить Apache через XAMPP Control Panel.
4. Открыть браузер и перейти по адресу `http://localhost/Lab7/`.
5. Выбрать нужное задание на главной странице.

PHP-файлы необходимо открывать через локальный веб-сервер, а не напрямую через `file://`.
